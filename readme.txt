CAP Pier Wall Liquid Dump
=========================

This mod adds a custom liquid dump intended to be placed on CAP Pier Wall support tiles.

Install
-------
1. Build the project.
2. Copy the generated folder to:
   %APPDATA%/Captain of Industry/Mods/CAP-PierWall-LiquidDump
3. Enable CAP Pier Wall first, then enable this mod.

Notes
-----
- The liquid dump checks every configured support cell individually.
- Support can be provided by multiple adjacent CAP Pier Wall entities.
- The support layer is placed above the wall collision volume to avoid IgnoreForCollisions.
- If the compiler reports API signature differences, send the exact error list and the file will be adjusted.
